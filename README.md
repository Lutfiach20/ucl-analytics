# Dashboard Analisis Performa Pemain (Machine Learning)

🔗 Live Demo: https://ucl-analytics-achmadlutfi.streamlit.app/

Aplikasi analisis performa pemain sepak bola berbasis machine learning (Random Forest) untuk membantu pengambilan keputusan berbasis data (data-driven).

---

## Tampilan Aplikasi
![Dashboard](docs/dashboard.png)

---

## Problem Statement
- Mengidentifikasi kelemahan tim berdasarkan data performa pemain
- Memberikan rekomendasi pemain untuk dijual berdasarkan analisis performa

---

## Fitur Utama
- Prediksi performa pemain (15 fitur statistik)
- Rekomendasi pemain serupa
- Analisis kelemahan tim
- Dashboard interaktif (Streamlit)

---

## Teknologi
- Python
- Streamlit
- Scikit-learn (Random Forest)
- Pandas, NumPy
- Google Colab (training model)

---

## Alur Sistem
1. Input data pemain
2. Preprocessing (scaling)
3. Prediksi dengan Random Forest
4. Output:
   - Analisis performa
   - Rekomendasi pemain
   - Visualisasi data
5. Analisis tambahan untuk kelemahan tim

---

## Use Case
- Scouting pemain
- Evaluasi performa tim
- Strategi transfer
